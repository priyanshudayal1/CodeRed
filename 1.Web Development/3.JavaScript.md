# Part 1: JavaScript Basics


## Introduction

- **JavaScript** : JavaScript is a high-level, interpreted programming language that conforms to the ECMAScript specification. JavaScript has curly-bracket syntax, dynamic typing, prototype-based object-orientation, and first-class functions.

- **JavaScript is a multi-paradigm, single-threaded, prototype-based, dynamic language, supporting object-oriented, imperative, and declarative (e.g. functional programming) styles.**

- **JavaScript in Web Development** : JavaScript is the programming language of HTML and the Web. JavaScript is easy to learn.



## Basic Syntax and Structure
- **Variables** : Variables are containers for storing data values.
 ```javascript
    const x = 5;
    let y = 6;
    var z = x + y;
    console.log(z);
```
- **Data Types** : JavaScript variables can hold many data types: numbers, strings, objects and more.
```javascript
    let length = 16;                            
    // Number
    let lastName = "Johnson";                   
    // String
    let x = {firstName:"John", lastName:"Doe"}; 
    //Object
    //boolean
    let isTrue = true;
    let isFalse = false;
    //undefined
    let car;
    //null
    let person = null;
```

- **Operators** : JavaScript has both binary and unary operators, and one special ternary operator, the conditional operator.
```javascript
    let x = 5;
    let y = 2;
    let z = x + y; // Addition
    let z = x - y; // Subtraction
    let z = x * y; // Multiplication
    let z = x / y; // Division
    let z = x % y; // Modulus
    let z = x ** y; // Exponentiation
    let z = x++; // Increment
    let z = x--; // Decrement
    let z = x == y; // Equal to
    let z = x === y; // Equal value and equal type
    //assignment operators
    let z = x = y; // Assign    
    let z = x += y; // Add and assign
    let z = x -= y; // Subtract and assign
    let z = x *= y; // Multiply and assign
    let z = x /= y; // Divide and assign
    let z = x %= y; // Modulus and assign
    let z = x **= y; // Exponentiation and assign
   //comparision operators
    let z = x > y; // Greater than
    let z = x < y; // Less than
    let z = x >= y; // Greater than or equal to
    let z = x <= y; // Less than or equal to
    let z = x != y; // Not equal
    let z = x !== y; // Not equal value or not equal type

    let z = x || y; // Logical or
    let z = !x; // Logical not
    //bitwise operators
    let z = x & y; // AND
    let z = x | y; // OR
    let z = ~ x; // NOT
    let z = x ^ y; // XOR
    let z = x << y; // Left shift
    let z = x >> y; // Right shift
```

- **Loops** : Loops can execute a block of code a number of times.

- **Objects** : JavaScript objects are containers for named values called properties or methods.
```javascript
    let person = {
        firstName: "John",
        lastName: "Doe",

        eyeColor: "blue"
    };
    //Accessing Object Properties
    let name = person.firstName;
    //Adding New Properties
    person.newProperty = "new value";
    //Deleting Properties
    delete person.age;
    //The JavaScript Object Constructor
    let person = new Object();

    person.lastName = "Doe";
    //The JavaScript this Keyword
    let person = {
        firstName: "John",
        lastName: "Doe",
```

- **Arrays** : JavaScript arrays are used to store multiple values in a single variable.
```javascript
    let cars = ["Saab", "Volvo", "BMW"];
    //Access the Elements of an Array
    let name = cars[0];
    //Change an Array Element
    cars[0] = "Opel";
    //The length Property
    let len = cars.length;
    //Looping Array Elements
    let text = "";
    for (i = 0; i < cars.length; i++) {
        text += cars[i] + "<br>";
    }
    //Adding Array Elements
    cars.push("Audi");
    //Associative Arrays
    let person = [];
    person[0] = "John";
    person[1] = "Doe";
    //Array Methods
    cars.pop(); // Removes the last element
    cars.shift(); // Removes the first element
    cars.unshift("Audi"); // Adds a new element to an array (at the beginning)
    cars.splice(2, 0, "Lamborghini"); // Adds a new element to an array (at a specified position)
    cars.splice(0, 1); // Removes elements from an array
    cars.concat(person); // Joins two or more arrays
    cars.slice(1, 2); // Selects a part of an array, and returns the new array
    cars.sort(); // Sorts an array
    cars.reverse(); // Reverses the elements in an array
```

# Part 2: JavaScript Advance : DOM Manipulation

## **Introduction**

- **DOM** : The Document Object Model (DOM) is a programming interface for web documents. It represents the page so that programs can change the document structure, style, and content. The DOM represents the document as nodes and objects. That way, programming languages can connect to the page.

- **DOM Manipulation** : The DOM allows you to manipulate the HTML and CSS of a webpage. You can change the text, the style, the attributes, and even the structure of an HTML document using the DOM.

- **JavaScript and DOM** : JavaScript can change all the HTML elements in the page. JavaScript can change all the HTML attributes in the page. JavaScript can change all the CSS styles in the page. JavaScript can remove existing HTML elements and attributes. JavaScript can add new HTML elements and attributes. JavaScript can react to all existing HTML events in the page. JavaScript can create new HTML events in the page.


- **DOM tree structure** : The DOM represents a document as a tree of objects. That way, programming languages can connect to the page. The DOM represents the document as nodes and objects. That way, programming languages can connect to the page.


## **Selecting DOM Elements** :

- **getElementById()** : The getElementById() method returns the element that has the ID attribute with the specified value.
```javascript
    document.getElementById("demo").innerHTML = "Hello World";
```

- **getElementsByClassName()** : The getElementsByClassName() method returns a collection of all elements in the document with the specified class name, as a NodeList object.
```javascript
    var x = document.getElementsByClassName("demo");
```

- **getElementsByTagName()** : The getElementsByTagName() method returns a collection of all elements in the document with the specified tag name, as a NodeList object.
```javascript
    var x = document.getElementsByTagName("p");
```

- **querySelector()** : The querySelector() method returns the first element that matches a specified CSS selector(s) in the document.
```javascript
    var x = document.querySelector("p");
```

- **querySelectorAll()** : The querySelectorAll() method returns all elements in the document that matches a specified CSS selector(s), as a static NodeList object.
```javascript
    var x = document.querySelectorAll("p");
```

## **Changing DOM Elements** :

- **Changing HTML** : The easiest way to modify the content of an HTML element is by using the innerHTML property.
```javascript
    document.getElementById("demo").innerHTML = "Hello World";

    document.getElementById("demo").innerText = "Hello World";
```

- **Changing Attributes** : The easiest way to change the attribute of an HTML element is by using the setAttribute() method.
```javascript
    document.getElementById("myImage").src = "landscape.jpg";
```

- **Changing Styles** : To change the style of an HTML element, use the style property.
```javascript
    document.getElementById("demo").style.fontSize = "35px";
```

- **Adding and Deleting Elements** : To add a new element to the HTML DOM, you must create the element (element node) first, and then append it to an existing element.
```javascript
    var para = document.createElement("p");
    var node = document.createTextNode("This is new.");
    para.appendChild(node);
    var element = document.getElementById("div1");
    element.appendChild(para);

    var parent = document.getElementById("div1");
```

## **Events** :

- **What are Events?** : Events are actions or occurrences that happen in the system you are programming, which the system tells you about so you can respond to them in some way if desired.

- **Common HTML Events** : An HTML event can be something the browser does, or something a user does.
```javascript
    <button onclick="document.getElementById('demo').innerHTML = Date()">The time is?</button>
```

- **Common JavaScript Events** : Here is a list of some common JavaScript events:
```javascript
    onchange
    onclick
    onmouseover
    onmouseout
    onkeydown
    onload
```

- **Event Listener** : The addEventListener() method attaches an event handler to the specified element.
```javascript
    document.getElementById("myBtn").addEventListener("click", displayDate);
```

- **Event Object** : When an event occurs, the event object is created by the browser. The event object contains all the information about the event, like where it happened, which key was pressed, etc.
```javascript
    document.getElementById("myBtn").addEventListener("click", function(event){
        alert(event.type);
    });
```

- **Event Bubbling** : Event bubbling is a type of event propagation where the event first triggers on the innermost target element, and then successively triggers on the ancestors (parents) of the target element in the same nesting hierarchy till it reaches the outermost DOM element.
```javascript
    document.getElementById("myDiv").addEventListener("click", function(){
        alert("You clicked on the div element!");
    });
    document.getElementById("myP").addEventListener("click", function(){
        alert("You clicked on the p element!");
    });
```

- **Event Capturing** : Event capturing is a type of event propagation where the event is first captured by the outermost element and then propagated to the inner elements.
```javascript
    document.getElementById("myDiv").addEventListener("click", function(){
        alert("You clicked on the div element!");
    }, true);
    document.getElementById("myP").addEventListener("click", function(){
        alert("You clicked on the p element!");
    }, true);
```

## **Form Validation** :

- **What is Form Validation?** : Form validation normally used to occur at the server, after the client had entered all the necessary data and then pressed the Submit button. If the data entered by a client was incorrect or was simply missing, the server would have to send all the data back to the client and request that the form be resubmitted with correct information. This was really a lengthy process which used to put a lot of burden on the server.

- **Client-Side Validation** : Client-side validation is an initial check and an important feature of good user experience; by catching invalid data on the client-side, the user can fix it straight away. This saves the time and effort of the user, as well as the server.

- **JavaScript Form Validation** : In this example, we are going to validate the name and password. If the name is empty, the function will return false (i.e., the form will not be submitted) and an alert will inform the user.
```javascript
    function validateForm() {
        var x = document.forms["myForm"]["fname"].value;
        if (x == "") {
            alert("Name must be filled out");
            return false;
        }
    }
```

- **HTML Form Validation** : HTML form validation can be done by JavaScript. If a form field (fname) is empty, this function alerts a message, and returns false, to prevent the form from being submitted.
```javascript
    <form name="myForm" action="/action_page.php" onsubmit="return validateForm()" method="post">
        Name: <input type="text" name="fname">
        <input type="submit" value="Submit">
    </form>
```
